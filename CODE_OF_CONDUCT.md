# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in full. The full text below summarises the bits that bind contributor behaviour here.

We pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

## How we apply it

> *Sine ira et studio* — without anger and without favour.

- **Disagree with the argument, never the person.** "This approach has these failure modes" is welcome; "you are an idiot for thinking this" is not.
- **Be precise.** "I think this breaks under condition X" lands; "this is bad" does not.
- **Be kind.** Kindness is a baseline, not a reward. It costs nothing.
- **Listen first.** Especially across boundaries — practitioner vs. researcher, junior vs. senior, different first languages, different time zones.
- **Be patient with non-native English.** This is a multinational project; we ship in English but read in many languages.
- **Public criticism, public credit.** When something fails, say so publicly; when something works, name the person who made it work.

## Examples of unacceptable behaviour

- Personal attacks, insults, or derogatory comments
- Trolling, sustained disruption, or hostile derailing
- Public or private harassment of any kind
- Sexualised language or imagery
- Publishing others' private information without explicit permission
- Conduct which a reasonable person would consider unprofessional in a workplace

## Enforcement

Instances of unacceptable behaviour can be reported confidentially to the project maintainers via the contact in [SECURITY.md](SECURITY.md). All complaints will be reviewed and investigated promptly and fairly. The maintainers reserve the right and responsibility to remove, edit, or reject contributions that violate this Code of Conduct.

Project maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project's leadership.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests, code review, code comments, project documentation, official communication channels) and in public spaces when an individual is officially representing the project.
