# DONNA voice-prompts

System prompts and conversational templates that drive DONNA's behaviour.

Categories (planned):
- `time-entry/` — extracting matter, hours, narrative from speech
- `task-delegation/` — parsing assignee, deadline, scope
- `clarifying-questions/` — when DONNA needs to disambiguate
- `confirmation/` — voice-back acknowledgements

These prompts are open under AGPLv3. Forks must keep them open.
