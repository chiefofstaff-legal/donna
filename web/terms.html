1.1 What it is. The DONNA widget at free.donnaoss.com/widget (the “Service”) is a free, publicly available demonstration of a cryptographic tamper-evidence mechanism: it computes a hash chain over the text you submit and applies a keyed message authentication code (HMAC-SHA256). We use the term “cryptographic notarisation” as a descriptive, technical name for this tamper-evidence.
